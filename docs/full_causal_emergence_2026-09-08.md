# Full causal emergence — 2026-09-08

## Question

Can the validated balanced operational universe be regenerated from local rules
alone, without carrying the 37-state manifold or 49-edge graph as external
metadata?

## Important correction

A previous test extended the compact 6-bit coordinate

`G = (h1, orientation, phase0, phase1, q0, q1)`

outside the 37 states on which that coordinate had been proven injective.  The
extended law generated 48 states and 96 edges.  A fitted local admissibility
classifier on those 96 edges required all seven inputs `(g0..g5,z)`, algebraic
degree 6 and 43 ANF terms.

That complexity is now interpreted as a **projection artifact**, not as evidence
for a new fundamental admissibility law.  The 6-bit coordinate is a minimal
coordinate of the validated operational manifold; it was never proven to be a
lossless coordinate of the whole formal causal state space.

## Correct test

Return to the complete public causal state

`X = (history3, topology3, phase3)`

with at most `8 * 8 * 3 = 192` formal states.

Starting only from the eight public initial states, apply the public local rule:

1. compute the policy index from topology and phase;
2. select the local action;
3. enumerate only bits allowed by that action;
4. update history, topology and phase locally.

No reachable-state whitelist and no reference edge table are used during graph
growth.  The generated graph is compared with the validated graph only after
generation.

## Interpretation

The operational geometry does not require a stored map of its 37 states.  It is
the reachable invariant set generated by:

`initial conditions + full causal state + local universe rule`.

The compact 6-bit coordinate remains valuable for analysing the already formed
operational manifold, but it must not be extrapolated outside that manifold as
if it were a globally complete state description.

This sharpens the current architecture:

- **full causal coordinate** `(history, topology, phase)` is the generative state;
- the public universe rule determines admissible local transitions;
- the 37-state operational manifold emerges by reachability;
- the 6-bit geometric coordinate is a minimal chart on that manifold;
- the `L + I + G` decomposition is a compact internal description of dynamics
  on the manifold, not yet a standalone global generator.

## Consequence for the research direction

The next useful question is no longer whether an additional 43-term
admissibility gate exists.  It is whether the complete generative causal state
can be reduced **without losing closure**.

The next experiment should search for a smallest coordinate `R(X)` such that:

1. it is computable locally;
2. it remains injective on every state reachable under its own generated
   dynamics, not merely on a preselected reference manifold;
3. its local transition law reproduces the 37-state/49-edge universe from the
   eight public initial conditions;
4. forward and reverse local updates remain exact.

This is a stricter notion than ordinary state compression: it asks for a
**generatively sufficient causal coordinate**.
