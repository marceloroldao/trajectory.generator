# Geometric invariant reduction — 2026-09-05

The reversible causal-edge label can be reproduced using semantic invariants derived only from local transition relations. This experiment does **not** claim a physical law; it is an exact statement about the current operational automaton.

## Result

The previous Boolean search required 7 primitive local bits (minimum within the tested ANF representation) to reproduce the reversible binary edge label over all 49 operational edges.

A new search over higher-level invariants reduced that description to **5 semantic invariants**. There are 7 distinct minimum 5-invariant subsets with zero label conflicts on the operational domain.

One exact minimum set is:

- `delta_alignment`: parity alignment between history change and topology change;
- `history_next_parity`: parity class of the next history state;
- `next_history_lsb`: next transition/data-side orientation bit;
- `phase_flip`: whether the public phase changes across the transition;
- `topology_direction`: sign class of the topology motion (down/same/up).

For this tuple, 37 distinct invariant observations cover the 49 operational edges and uniquely determine the canonical reversible label `z`.

Other exact 5-invariant descriptions exchange some of these quantities for equivalent orientation/parity/step-weight invariants. This shows the representation is not unique, but the tested semantic family requires at least 5 invariants for exact discrimination.

## Interpretation

The local reversible law can therefore be written abstractly as

```text
z_t = F(A_t, P_{t+1}, b_{t+1}, Δφ_t, D^Q_t)
```

where `A` denotes delta alignment, `P` a history parity class, `b` the next history orientation/data bit, `Δφ` the phase-change class, and `D^Q` the topology-motion direction.

Combined with the causal-coordinate result,

```text
C_t <--- z_t ---> C_{t+1}
```

is bidirectionally deterministic on the operational graph.

The important distinction is that the edge label no longer needs a global edge lookup or raw causal-class IDs. It can be inferred from local relational invariants. However, these invariants are still defined on the current symbolic automaton. They should not be interpreted as independent physical coordinates without additional evidence.
