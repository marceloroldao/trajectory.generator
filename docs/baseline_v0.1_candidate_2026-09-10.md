# trajectory.generator — mathematical baseline v0.1

Date: 2026-09-10
Status: FROZEN MATHEMATICAL BASELINE

## Frozen claims

1. The admissible trajectory language is generated by the fixed 4-bit private-state automaton and phase `t mod 3`.
2. A whole trajectory at horizon T has a bijective integer address in `[0,N(T))`.
3. At T=218, `N(T)=9,131,204,053,820,206,208`, so the complete address space fits in 63 bits; T=219 requires 64 bits.
4. The joint dyadic address is online-updatable using only O(log T) dyadic blocks and supports random access by descending one selected block.
5. Whole-slice public state counts are deterministic functions of time. Their growth sector is generated by the scalar recurrence

   `g[n+3] = 2*g[n+2] - g[n+1] + g[n]`, with `g0=1, g1=0, g2=0`.

6. No stored public trajectory history is required to reconstruct whole-slice counts.
7. Interval-conditioned path counts `paths_count(t0,t1,starts,ends)` are derivable directly from the fixed 3-periodic transition law using 16x16 transition matrices and exponentiation by squaring. No DP over the past trajectory is required.
8. Direct interval-conditioned counts were independently cross-validated against step-by-step DP across representative phases and lengths, exhaustive endpoint pairs for those cases, plus 500 random endpoint-set tests.

## Explicit non-claims

- The address is not a cryptographic hash.
- No claim of compression below the information-theoretic rank of the restricted language is made.
- A simple scalar affine update law directly on the packed integer address has not been found.
- Complexity statements count structural/matrix operations separately from big-integer arithmetic cost.
- The current reference implementation is a correctness baseline, not a performance-optimal implementation.

## Frozen invariants

Any future optimization or alternate implementation must preserve all of the following:

- exact bijection / roundtrip;
- exact admissible-language counts;
- exact counts through at least T=219;
- 63/64-bit frontier at 218/219;
- online append produces the same joint address as direct ranking;
- random access returns the same transition symbol as exact block decoding;
- scalar whole-slice counts equal independent dynamic-programming counts;
- direct matrix interval counts equal independent step-by-step DP counts;
- no hidden trajectory history, whitelist, or precomputed trajectory map is required by the mathematical contract.

## Reference mathematical contract

The frozen baseline can be summarized as:

`(A_T, T) <-> admissible trajectory`

with:

- 4-bit private causal state;
- public phase `t mod 3`;
- fixed transition laws;
- whole-slice counts derivable from time;
- interval path counts derivable from `(t0,t1,start,end)` and fixed laws;
- joint dyadic ranking for online evolution and random access.

This file marks the mathematical baseline v0.1 as frozen. Future work should optimize implementation, reduce constants, test portability, and explore applications without silently changing these invariants.
