# Modal horizon-free trajectory address — 2026-09-09

## Result

The public count field used by the horizon-free endpoint-rank codec does not need to be propagated as a raw 16-state vector.

For phase-aligned slices `V_n = C_{3n}`, the exact reachable characteristic polynomial factors as

```
x (x-1)^2 (x+1)^2 (x^3 - 2x^2 + x - 1)
```

The four pairwise-coprime sectors were isolated by exact rational CRT projectors.

The initial count vector therefore decomposes into:

- a one-dimensional transient sector (`x`), which vanishes after one Floquet period;
- a two-dimensional `+1` Jordan sector, whose evolution is an explicit affine function of `n`;
- a two-dimensional `-1` Jordan sector, whose evolution is an explicit alternating affine function of `n`;
- a three-dimensional growth sector governed by `x^3 - 2x^2 + x - 1`.

Only the growth sector requires live public amplitudes. In the Krylov basis `(g0, Fg0, F^2g0)`, write the current growth component as

```
a*g0 + b*g1 + c*g2
```

Then one Floquet period updates the three amplitudes exactly by

```
(a,b,c) -> (c, a-c, b+2c)
```

with initial value `(1,0,0)`.

All other contributions to `C_{3n}` are fixed functions of `n` and `(-1)^n`. For intermediate physical phases, the fixed phase transition matrices lift `C_{3n}` to `C_{3n+1}` and `C_{3n+2}`.

## Validation

`experiments/modal_horizon_free_address.py` reconstructs the full per-endpoint count field from these modal components and compares it against the original dynamic-programming field.

Exact equality was verified for every physical time `t = 0..220`.

The horizon-free endpoint-rank codec was then rebuilt using only the modal count provider. Validation passed:

- exhaustive address roundtrips for `T = 0..9`;
- 200 random roundtrips each at `T = 16, 64, 128, 200, 218`;
- exact frontier counts:

```
N(218) = 9,131,204,053,820,206,208
N(219) = 10,214,739,716,735,776,832
```

Thus the 63-bit frontier remains exactly 218 transitions.

## Interpretation

The public "universe field" needed by the online reversible address can now be represented operationally as:

```
public clock n / phase
+ parity (-1)^n
+ three live integer growth amplitudes (a,b,c)
+ fixed public basis vectors / phase maps
```

rather than a dynamically propagated 16-entry count vector.

This is an exact algebraic reduction, not an approximation or entropy claim. The three amplitudes are still a public deterministic field generated by the rules and elapsed time; they are not private trajectory data.
