# Multilayer universe acceptance gate

## Objective
Test whether a bounded endpoint generated by local trajectory dynamics can retain the genuinely free innovations of a much longer, otherwise deterministic trajectory.

This does not claim compression of arbitrary independent bits.

## State accounting
- X_t: input-dependent endpoint state. Every bit counts toward W.
- U_t=(H,V,Z,...): public universe state. It is admissible as public structure only if completely independent of the input and reproducible from public constants plus t.
- Any input-dependent component added to U must immediately be counted in W.

## Gates
G1: endpoint updated online from previous endpoint, public universe, current innovation and time.
G2: after encoding retain only (X_T,T) plus fixed public laws/constants.
G3: enumerate every history with zero, one or two innovations and require distinct endpoints.
G4: K>=3 sampling is exploratory only, never proof.
G5: compare with the cardinality ceiling sum(C(T,j),j=0..K) <= 2^W.
G6: require an exact decoder from (X_T,T), without stored trajectory tables.
G7: preferred target is local reverse: infer the latest innovation/predecessor from current endpoint plus current public universe and reverse one step.

## Widths
63 bits remains a historical baseline. Active research widths are 128, 256 and 512 bits. All input-dependent bits count toward the information budget.

## Success criterion
The interesting result is not T>W by itself. It is exact reconstruction for T>>W when independent innovations fit the W-bit information bound, with those innovations embedded by natural online dynamics rather than a separately computed rank/address.
