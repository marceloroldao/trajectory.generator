# Affine translation address dynamics — 2026-09-20

## Result

The full-universe streaming address has a simpler dynamical form than the
rank-block implementation initially suggested.

Let the packed trajectory address at physical transition time `t` be:

```text
S_t = endpoint_offset_t(u) + rank_t
```

where `u` is the current public graph node and `rank_t` is the rank inside
that endpoint bucket.

For a public physical edge:

```text
e: u -> v
```

the within-bucket rank is preserved. Only the public bucket offsets change.

Therefore every physical transition is exactly:

```text
S_(t+1) = S_t + Delta(e,t)
```

with:

```text
Delta(e,t)
  = endpoint_offset_(t+1)(v)
  + incoming_edge_offset_t(e)
  - endpoint_offset_t(u)
```

The translation depends on:

- public edge;
- public physical time;
- public graph law;
- public count field.

It does **not** depend on the trajectory-specific rank inside the source bucket.

## Reverse

The current address first identifies the target endpoint bucket and then the
incoming-edge sub-block. Once the edge is known:

```text
S_t = S_(t+1) - Delta(e,t)
```

The implementation verifies that this subtraction gives exactly the same
predecessor address as the original rank-block decoder.

So the trajectory address is now explicitly a reversible state transformation,
rather than only a batch combinatorial rank.

## Delta is generated by the same Floquet law

Every endpoint offset and incoming-edge offset is an integer linear functional
of the public count vector.

The public count vector satisfies the Floquet recurrence. Therefore, for an edge
whose source phase is `p`, the phase-aligned sequence

```text
Delta(e, p + 3q)
```

must satisfy the same Floquet recurrence.

## Interpretation

The operational dynamics can now be written as:

```text
(public causal edge, public time, address)
              |
              v
        address + Delta
```

and in reverse:

```text
current address
    -> locate public predecessor block
    -> identify edge
    -> subtract Delta
    -> predecessor address
```

The important structural point is that `Delta` itself is not an arbitrary
time table. Its phase-aligned sequence is generated by the same small public
Floquet recurrence as the count field.

Thus the address evolution is a public affine action over one integer state.

## What remains external to the scalar address

The reverse decoder still needs to answer two partition questions:

1. which endpoint bucket contains the current integer address?
2. inside that endpoint bucket, which incoming-edge block contains its rank?

The current implementation answers those questions by reconstructing the
endpoint-count vector for the relevant time.

But every bucket boundary is also a scalar linear functional of that vector.
Therefore each boundary sequence must obey the same Floquet recurrence.

This creates the next gate:

> replace full count-vector reconstruction during reverse with direct scalar
> evaluation of only the endpoint and incoming-edge boundaries needed to locate
> the predecessor block.

If successful, the reverse machine can operate on:

```text
address
+ public time
+ small recurrence
+ scalar partition boundaries
```

without materializing the full count field.

## Conceptual boundary

The integer address is still an explicitly constructed enumerative coordinate.
This result does not prove that the raw causal node alone contains the past.

What it does prove is stronger than the earlier batch interpretation:

- the address is a genuine evolving state;
- every public edge acts by an additive translation;
- the translation is independent of trajectory rank;
- the translation law is itself generated by the universe's compact recurrence;
- reversal uses the exact inverse translation once the predecessor block is
  identified.
