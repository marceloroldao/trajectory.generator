# Floquet count-field recurrence — 2026-09-20

## Purpose

The full-universe streaming graph address proved that the historical topological
trajectory language can be recovered one physical edge at a time from a final
enumerative address.

Its reference implementation still cached the public endpoint-count field:

```text
D(v,t) = number of admissible paths ending at node v at time t
```

for every reached time. That costs `O(V*T)` big integers.

This result removes that time-growing table for the phase-lifted topological
universes.

## Step 1 — exact vector recurrence

For a finite public graph,

```text
D_(t+1) = A^T D_t
```

so the Krylov sequence generated from the public initial count vector satisfies
an exact finite linear recurrence:

```text
D_(n+d) = sum(c_i D_(n+i), i=0..d-1)
```

with `d <= V`.

The recurrence is derived by exact rational elimination and then verified over
additional public steps.

After pruning graph states that are unreachable from the eight public initial
lifted states, the three historical topological candidates give:

```text

robust_208           46                    31
balanced_221         37                    23
long_239             34                    22
```

## Step 2 — reverse the count field itself

The leading zero coefficients correspond to a transient factor `x^m`.

After removing that factor, the recurrence has a non-zero constant term:

```text
W_(n+r) = a_0 W_n + a_1 W_(n+1) + ... + a_(r-1) W_(n+r-1)
```

so:

```text
W_n =
  [W_(n+r) - sum(a_i W_(n+i), i=1..r-1)] / a_0
```

This lets the count field walk backward together with trajectory decoding.

The full-graph reverse windows are:

```text
candidate      transient m   reverse window r
robust_208          4               27
balanced_221        2               21
long_239            7               15
```

CI verified `backward_count_identity=True` for all three candidates.

This already changes public count memory from horizon-growing `O(V*T)` to a
fixed recurrence basis plus a fixed reverse window.

## Step 3 — exploit public phase

The causal graph is phase-lifted modulo 3. Every public physical edge advances:

```text
phase -> phase+1 mod 3
```

and all eight valid initial lifted nodes begin at phase 0.

Therefore only one phase slice can carry non-zero counts at any physical time.

A 3-step Floquet multigraph is constructed automatically on the phase-0 slice.
Duplicate 3-step targets are retained as distinct public paths.

For:

```text
t = 3q + r
```

the exact physical count field is regenerated by:

1. recover the phase-0 count vector at period `q`;
2. embed it into the full graph;
3. apply `r` ordinary public transitions.

The resulting minimum Floquet recurrences are:

```text

robust_208           16             31            11
balanced_221         13             23             8
long_239             12             22             8
```

```text
balanced_221
(0,1,-1,0,1,-3,1,2)

```

The reverse Floquet windows shrink to:

## Step 4 — discard the seed basis

The first `d` phase vectors are needed to derive the recurrence, but they do
not need to remain resident.

In compact mode:

```text
retain_basis = False
```

a distant period row is evaluated by:

```text
x^q mod m(x)
```

to obtain recurrence weights, while the needed seed vectors are regenerated
sequentially from the public initial vector and public graph.

The CI gate verifies:

```text
retained_basis_integers = 0
```

for all three Floquet codecs.

No time-indexed table and no persistent Krylov basis are required.

## Interpretation

The public time table has been removed from the operational requirement.

The reverse decoder now needs, conceptually:

```text
final address
physical length
public graph law
small recurrence coefficients
short reverse count window
```

The window itself is regenerated from the law and final physical time.

The count field then walks backward with the trajectory.

This is materially closer to the original trajectory.generator objective:

```text
where I am + public universe law + public time
    -> where I came from
```

without a trajectory history table and without a count table growing with time.

## Important boundary

The result still uses an **enumerative address coordinate** in addition to the
raw causal node.

It proves that the address-support field can be regenerated compactly from the
universe law; it does not prove that the raw causal state alone uniquely
contains all past branch choices.

That deeper distinction remains the main conceptual boundary.

## Next gate

Two directions are now meaningful:

1. derive the address transition from a still smaller endogenous modal
   coordinate rather than reconstructing a full endpoint-count row;
2. search for a universe whose raw causal geometry itself supplies a
   branch-separating reverse coordinate, so the enumerative address becomes
   unnecessary or collapses into the causal state.

The first is an engineering compression problem. The second is the stronger
trajectory.generator hypothesis.
