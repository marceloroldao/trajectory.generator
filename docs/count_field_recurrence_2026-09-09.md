# Compact recurrence for the public count field

Date: 2026-09-09

## Goal

The horizon-free endpoint address uses the public field

`C_t(P) = number of admissible histories reaching private state P at elapsed time t`.

The first implementation recomputed `C_t` by dynamic programming from time zero. This experiment asks whether the count field has a lower-dimensional deterministic recurrence.

## Phase-resolved linear dynamics

The private state has 16 possible four-bit values and the public phase is `phi=t mod 3`. For each phase there is a fixed 16x16 integer transition matrix `M_phi` such that

`C_{t+1} = M_phi C_t`.

The implementation was checked exactly against the existing dynamic-programming counts for t=0..30.

## Three-step Floquet operator

For phase-aligned slices define

`F = M_2 M_1 M_0`.

Then

`C_{t+3} = F C_t`

whenever t is phase aligned.

Starting from the public initial count vector, the Krylov space generated by repeated application of F has exact rational rank 8, although the raw vector has 16 components.

Therefore the phase-aligned count field satisfies an exact vector recurrence of order 8.

Let `V_n = C_{3n}`. Then

`V_{n+8} = V_{n+1} - V_{n+2} + V_{n+4} - 3 V_{n+5} + V_{n+6} + 2 V_{n+7}`.

Equivalently, with all terms on one side,

`V_{n+8} - 2V_{n+7} - V_{n+6} + 3V_{n+5} - V_{n+4} + V_{n+2} - V_{n+1} = 0`.

This recurrence was validated exactly for 100 Floquet periods using integer/rational arithmetic.

## Total-path scalar recurrence

The scalar sequence

`N_t = sum_P C_t(P)`

also satisfies a fixed recurrence. The first exact recurrence found has order 20:

`N_t = N_{t-1} + N_{t-3} - N_{t-4} + 2N_{t-6} - 2N_{t-7} - N_{t-9} + N_{t-10} - N_{t-18} + N_{t-19}`.

It was validated through t=220.

This reproduces the known 63-bit boundary exactly:

- `N_218 = 9,131,204,053,820,206,208 < 2^63`
- `N_219 = 10,214,739,716,735,776,832 > 2^63`

## Interpretation

The public universe-count field is not an arbitrary 16-dimensional object. On the reachable trajectory family, the phase-aligned dynamics occupies an 8-dimensional linear subspace.

This means the horizon-free address need not conceptually depend on an ever-growing history table. The counts can be generated by a fixed recurrence determined by the universe rules and the elapsed time.

The current strongest contract is therefore:

`A_{t+1} = F_addr(A_t, P_t, z_t, C_t)`

with

`C_t` generated autonomously from fixed public recurrences and `t`, without knowing the final horizon T and without storing the trajectory history.

## Caution

This is a computational property of the current finite automaton. It should not be interpreted as a universal physical law. The recurrence coefficients are specific to this constructed universe.
